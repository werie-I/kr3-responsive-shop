# Отчёт по доступности DOMA — практическая работа №13

## Проверки по исходному коду

| Проверка | Результат |
|---|---|
| Один основной `h1` на каждой HTML-странице | Выполнено: 10 из 10 страниц |
| Один `main` на каждой HTML-странице | Выполнено: 10 из 10 страниц |
| Ссылка пропуска к основному содержимому | Есть на всех 10 страницах |
| Альтернативные описания изображений | Статические изображения проверены; пустых и отсутствующих `alt` не осталось |
| Подписи полей форм | Все найденные поля имеют связанные `label` или находятся внутри `label` |
| Фокус клавиатуры | Есть общий `:focus-visible`, контрастный индикатор, стили skip-link |
| Мобильное меню | Добавлены `aria-controls`, `aria-expanded`, динамическое имя кнопки и связь с раскрываемой областью |
| Уменьшение анимации | Сохранена поддержка `prefers-reduced-motion` |
| Таблица информации о товаре | Добавлена семантическая таблица с прокруткой внутри контейнера на узком экране |

## Исправления

- Усилены текстовые акценты и цвет индикатора фокуса для контрастности.
- Для интерактивных кнопок избранного задаются понятные имена и `aria-pressed`.
- Динамические изображения карточек, товара и корзины получают описательные `alt`.
- Для статусов формы сохранены live-регионы `role="status"`.
- Кнопки и ссылки остаются нативными HTML-элементами.

## Ограничение отчёта

Это предварительная проверка HTML/CSS/JavaScript исходников. Она **не является результатом Lighthouse** и не содержит выдуманных баллов. Для завершения пункта методички нужно открыть опубликованный сайт в Chrome DevTools → Lighthouse → Accessibility и сохранить настоящий HTML-отчёт или скриншот в эту папку. Порядок запуска описан в `lighthouse/README.md`.
