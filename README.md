# DOMA — мебельный интернет-магазин

Многостраничный сайт на HTML5, CSS3 и JavaScript. Сохранена исходная визуальная система DOMA: палитра, типографика, сетки, карточки, кнопки и композиция. Интерактивность реализована на JavaScript без дополнительной сборки.

## Страницы
- `index.html` — главная и анимация сборки кресла.
- `catalog.html` — каталог, фильтры и сортировка.
- `product.html` — карточки товаров (`?item=sofa`, `?item=table`, `?item=shelf`, `?item=bed`).
- `favorites.html` — избранные товары.
- `account.html` — интерфейс личного кабинета.
- `search.html` — результаты поиска.
- `about.html` — о бренде.
- `delivery.html` — доставка и оплата.
- `contacts.html` — контакты и интерактивная карта Яндекса.
- `order.html` — оформление заказа.

## Возможности
- Поиск по каталогу.
- Корзина и избранное с сохранением в `localStorage`.
- Переключение светлой и тёмной темы.
- Выпадающее меню дополнительных разделов: четыре основные ссылки остаются в шапке.
- Чат-консультант с ответами на частые вопросы.
- Анимированная сборка кресла из отдельных элементов.
- Кнопка «наверх» в виде мебельного подъёмника с индикатором прокрутки.
- Адаптивное меню, формы с HTML-валидацией и поддержка `prefers-reduced-motion`.

## Запуск
Откройте `index.html` в браузере или запустите папку через Live Server в VS Code. Дополнительная сборка не требуется.

Интерфейс входа и оформление заказа работают на стороне браузера; для реальной авторизации, обработки заказов и платежей потребуется серверная часть.
