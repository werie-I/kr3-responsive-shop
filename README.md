# DOMA — мебельный интернет-магазин

Многостраничный сайт на HTML5, CSS3 и JavaScript. Сохранена исходная визуальная система DOMA: палитра, типографика, сетки, карточки, кнопки и композиция. Интерактивность реализована на JavaScript без дополнительной сборки.

## Страницы
- `index.html` — главная и анимация сборки кресла.
- `catalog.html` — каталог, фильтры и сортировка.
- `product.html` — карточки товаров (`?item=sofa`, `?item=table`, `?item=shelf`, `?item=bed`).
- `favorites.html` — избранные товары.
- `account.html` — интерфейс личного кабинета.
- `search.html` — результаты поиска.
- `about.html` — о бренде.
- `delivery.html` — доставка и оплата.
- `contacts.html` — контакты и интерактивная карта Яндекса.
- `order.html` — оформление заказа.

## Возможности
- Поиск по каталогу.
- Корзина и избранное с сохранением в `localStorage`.
- Переключение светлой и тёмной темы.
- Выпадающее меню дополнительных разделов: четыре основные ссылки остаются в шапке.
- Чат-консультант с ответами на частые вопросы.
- Анимированная сборка кресла из отдельных элементов.
- Кнопка «наверх» в виде мебельного подъёмника с индикатором прокрутки.
- Адаптивное меню, формы с HTML-валидацией и поддержка `prefers-reduced-motion`.

## Запуск
Откройте `index.html` в браузере или запустите папку через Live Server в VS Code. Дополнительная сборка не требуется.

Интерфейс входа и оформление заказа работают на стороне браузера; для реальной авторизации, обработки заказов и платежей потребуется серверная часть.

Изображения загружаются с Unsplash, карта — из Яндекс.Карт.

## Практические работы №13–14 — аудит доступности, SEO и адаптивность

### Практика №13: A11y и SEO
- Проверены семантическая структура страниц, `main`, `h1`, подписи форм и доступные названия элементов.
- Добавлены подробные описания `alt` для 12 товаров в массивах `products`, `furniture` и `catalog`; JavaScript передаёт эти значения в `img.alt` при выводе карточек, страницы товара, избранного и корзины.
- Добавлены уникальные `title` и `meta description`, Open Graph и Twitter Card.
- Карточка товара обновляет SEO-метаданные при выборе товара через параметр `item`.
- Добавлена структурированная разметка Schema.org: `Organization` и `WebSite` на главной странице, `Product` на странице товара. Данные `Product` обновляются при выборе товара через `?item=...`.
- Страницы поиска, избранного и кабинета закрыты от индексации через `noindex,follow`.
- Добавлена XML-карта `sitemap.xml` с публичными страницами и товарными URL. Путь к карте указан в `robots.txt`.
- Отчёт: `reports/seo-audit.md`.

### Практика №14: финальная адаптивная проверка
- В `css/responsive.css` оформлен отдельный Mobile First слой и медиазапросы для мобильных, планшетов и широких экранов.
- Проверены и закреплены адаптивные состояния навигации, каталога, карточек, страницы товара, формы и подвала.
- Для изображений добавлены `srcset`, `sizes`, размеры и отложенная загрузка там, где это уместно.
- Для таблицы сведений о товаре предусмотрен горизонтально прокручиваемый контейнер на узких экранах.

Рекомендуемые контрольные ширины: **360, 430, 768, 1024 и 1440 px**.

**Примечание:** сайт остаётся учебным каталогом DOMA. Названия Forma/Orbit и т. п. — подписи товаров в макете, а не подтверждённые марки производителей. Точные бренды, модели и характеристики не добавлялись без исходных данных.


### SEO-разметка и изображения

- Подробные `alt`-описания хранятся рядом с URL изображения в данных товара:
  - `js/main.js` — поле `imageAlt`;
  - `js/kr3.js` — поле `alt`;
  - `js/order.js` — поле `alt`.
- `js/main.js` присваивает описание выбранного товара свойству `detailImage.alt`.
- `js/kr3.js` использует `item.alt` при создании HTML-карточки, включая каталог и избранное.
- `js/order.js` передаёт `item.alt` в изображение позиции корзины.
- В `product.html` находится JSON-LD с типом `Product`; `js/main.js` обновляет его при выборе товара.
- В `index.html` добавлена JSON-LD-разметка `Organization` и `WebSite`.
- `sitemap.xml` перечисляет главную, каталог, информационные страницы и страницы 12 товаров.
- `robots.txt` разрешает обход сайта и указывает расположение карты сайта.

**О фреймворке:** DOMA — статический сайт на HTML, CSS и JavaScript без CMS и серверной сборки. WordPress-плагины вроде The SEO Framework к такому проекту напрямую не подключаются. Вместо неиспользуемой зависимости применены открытые веб-стандарты Schema.org и JSON-LD, а также `sitemap.xml` и `robots.txt`. Lighthouse используется как инструмент аудита, а не как SEO-фреймворк.

**Проверка после обновления:** ранее сохранённые HTML-отчёты Lighthouse относятся к предыдущему состоянию проекта. После этих изменений нужно повторно запустить Lighthouse в Chrome для актуальных результатов и заменить соответствующие отчёты в `lighthouse/`.
